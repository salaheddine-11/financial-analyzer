
# Financial Statement Analyzer

Project 1 of my finance + AI portfolio.

## Goal

Upload a balance sheet and income statement, then calculate:

- liquidity ratios
- leverage ratios
- profitability ratios
- activity ratios
- DuPont decomposition
- trend analysis
- red flags

## Status

Phase 0 complete: environment setup and basic Streamlit app working.

## Tools

- Python
- pandas
- Streamlit
- Plotly
- uv
- Git

## Run locally

```bash
uv run streamlit run app.py
```
